# PRD：合并系统 — A股全景观察（仪表盘 × 每日资金观察 × 估值判断）

日期：2026-08-05 · 状态：待实现 · 模块：market-radar

## 问题陈述

当前两个模块独立运行、独立推送：
- **A股全景仪表盘**（market_dashboard.py / rally-health.yml，工作日 16:00）：大盘概况、板块异动、三周期、操作建议——用户自用决策工具
- **每日资金观察**（ltc_* / long-term-capital.yml，工作日 16:30）：板块资金流归因、承接周期、南向、回购、AI 解读——认知产品

问题：① 每天两张卡，内容有重复（板块资金流、板块 K 线）；② 数据基建不统一（仪表盘无熔断留痕，资金观察有）；③ **没有估值判断**——现有"价格位置分位"只描述位置，不回答"贵还是便宜"。

目标：合并为一个系统、一张卡，新增**估值判断**（贵/便宜），以 A 股全景仪表盘为骨架。

## 目标用户

用户本人（自用决策工具）。合并后仍是决策工具：操作建议保留；资金观察的认知内容（归因/承接/解读）作为增强并入。

## 估值判断框架（用户确认版，2026-08-05）

### 数据链（三级兜底）
1. **PE 分位**：中证官方 index-perf 接口（`peg` 字段=PE(TTM 总股本口径)，已验证：沪深300 2015-2026 全历史 2816 天，行业指数全覆盖）——近 10 年分位
2. **PB 分位**：BaoStock 个股 pbMRQ 按行业市值加权聚合当前值；历史分位用**每日留痕积累**（冷启动标注"PB 分位积累中"，约 20 交易日后可用）
3. **兜底**：两级都取不到 → 退回现有价格位置分位（5 年区间），**标注"基于价格位置，非 PE/PB"口径**

### 判定规则（综合判断，非单一指标）
- **基础**：PE 分位 + PB 分位双指标
- **修正 1 · 盈利周期**（用户修正版，方向正确）：
  - 盈利低谷 + 高 PE 分位 → 可能错杀 / 可能陷阱（看盈利方向：回升→错杀；下滑→陷阱）
  - 盈利高峰 + 低 PE 分位 → 假便宜，警惕周期见顶
  - 盈利方向数据：优先 PE 序列位置（PE 低点≈盈利高点）推断，标注近似口径
- **修正 2 · PB 交叉验证**（周期股看 PB，成长股看 PE）：
  - PE、PB 双低 → 真便宜，可信度高
  - PE 高、PB 低 → 盈利在底部（PB 说真话），需判断盈利能否回升
  - PE 低、PB 高 → 盈利在顶部（假便宜），警惕
  - 两者不一致 → 不单独下结论，标矛盾
- **修正 3 · 资金验证（持续性）**：用现有留痕（history.jsonl）
  - 单日大额流入 → "观察"
  - 连续 ≥3 日净流入 → "流入确认"（流出同理）
  - 确认后四象限：低估+流入确认=共振（真便宜）/ 低估+流出确认=可能还有下探 / 高估+流入确认=拥挤警惕 / 高估+流出确认=见顶确认
- **置信度**：估值+盈利+资金三维同向=高 / 两维同向=中 / 维度矛盾=低（结论只写"观察"）
- **输出**：结论（便宜/合理/贵/需警惕/观察）+ 主导维度 + 置信度 + 标注"推断"

## 合并设计

### 重复部分取舍（用户授权以谁为准）
| 功能 | 取舍 | 理由 |
|---|---|---|
| 板块资金流 | 以资金观察为准 | 熔断/留痕/参照/归因成熟 |
| 板块 K 线 | 以资金观察为准 | 东财→同花顺兜底链+熔断 |
| 板块异动 entry/hold/watch/avoid | 保留（仪表盘） | 独有 |
| 三周期/操作建议 | 保留（仪表盘） | 用户确认，决策工具核心 |
| 北向资金 | 删除 | 数据源已死（官方停披露） |
| AI 解读 | 以资金观察为准（事实清单+校验+模板） | 仪表盘 ai_audit 无护栏 |
| 熔断/留痕/参照/诚实降级 | 资金观察的统一基建 | 一套代码 |
| 交易手册 TRADING_MANUAL | 保留，标注"参考材料，非今日数据" | |

### 卡片形态（以仪表盘为骨架重排）
1. 顶部：**估值判断表**（板块 | 分位(PE/PB) | 结论 | 主导维度 | 置信度）
2. 大盘概况（仪表盘）
3. 板块异动 + 操作建议（仪表盘）
4. 今日资金（归因/承接/南向/回购，资金观察）
5. AI 解读（资金观察护栏版）
6. 诚实声明

### 推送
- 工作日 16:15（两个系统 16:00/16:30 的居中），一张卡
- 观察对象日期规则沿用：卡片日期=数据日期，data_date > last_pushed 才推（跨夜/重复/节假日全覆盖）

## 非功能需求
- 估值判断的 PE 数据源失败 → 降级链（PE 无→PB 无→价格位置兜底），标注口径；全挂 → 估值区块"暂无数据"
- 全流程 ≤8 分钟（沿用熔断）
- 操作指令保留但代理指标标注"通常被认为"；推断标注
- 测试真实断言；估值判定逻辑纯函数化（注入分位数据）

## 验收标准
1. 合并后单卡单推（工作日 16:15），无重复推送
2. 估值表覆盖现有仪表盘全部板块 + 资金观察 focus 板块（≥10）
3. PE 分位来自中证全历史；PB 缺失时走三级降级链且标注口径
4. 盈利周期修正生效（构造测试：盈利低谷+高PE分位 → 错杀/陷阱分支）
5. 资金持续性：单日=观察、连续≥3日=确认（用留痕）
6. 置信度三维规则生效（同向/矛盾测试）
7. 操作建议保留；北向不再出现
8. 全链路 dry-run：估值表+概况+异动+资金+解读+声明齐全

- 真实盈利数据源（利润/ROE 历史）——用 PE 序列位置近似，标注口径
- 美股交易机会系统改动（本次只做 A 股合并）
- 两个老系统的审计修复分支（feat/audit-fix-*）独立于本合并进行
