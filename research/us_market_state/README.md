# 美股多市场状态日报

用一句话说：**每天告诉你美股大盘、纳指、半导体、中概现在处于什么阶段，风险在积累还是在释放，以及按规则现在该怎么做。**

它不是预测“哪天见顶/见底”，而是把价格和宏观数据翻译成普通人能看懂的状态：
- 现在是在下跌、恐慌、止跌、修复，还是趋势确认？
- 过去 20 天，广度、信用、波动是在恶化还是改善？
- 这个状态对你手里的美股/七姐妹/中概意味着什么？
- 现在该防守、试探、加仓，还是持有？

## 两种推送

| 类型 | 时间 | 内容 | 工作流 |
|---|---|---|---|
| **日报卡片** | 美股收盘后（北京周二~周五 07:30） | 五个市场 + 广度/信用/波动 + 市场声音 + 七姐妹 + 今天怎么做 | `daily-report.yml` |
| **周报卡片** | 周六 09:00（覆盖周五美股） | 完整解释 + 周线变化 + 市场声音 + 小白词典 | `us-market-state.yml` |

两种卡片都走 **内部群 Bot + 外部群 Webhook 双推**；标题/颜色按阶段变化（防守红、观察橙、修复绿、数据不足灰），正文用 markdown 加粗重点、分隔线分块。

## 市场声音（独立 AI 摘要层）

- **Tavily** 搜最近 7 天公开的卖方/首席经济学家观点；**Agnes** 只做“谁说了什么、最近改了什么、分歧在哪”的摘要。
- 硬规则：每条观点必须带材料里出现过的来源 URL；无来源直接丢弃；AI 不参与状态、评分和动作。
- AI/Tavily 失败时卡片照常发，只少“市场声音”这一块，不影响状态判断。
- 相关环境变量：`AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`、`TAVILY_API_KEY`。

`daily-report.yml` 已从原来的 `main.py` 切换到 `run_daily.py`；旧的美股 AI 日报不再定时运行，`main.py` 保留作归档。A 股的 `cycle-panel.yml` 不受影响。

**干跑模式**：定时任务默认 `--shadow`，飞书卡片带【干跑】前缀，不写状态、不影响正式去重；确认后用 `workflow_dispatch` 的 `live=true` 切正式。

**不做盘中提醒**：券商 APP 已经做价格提醒，重复做会制造噪音。本系统的重心是提前看风险积累和趋势阶段，不是跌了才通知。

## 数据频率

- 领先指标（信用利差、广度、VIX、等权/市值权）是日频/周频，不需要盘中实时报价。
- 日报用美股收盘后的日线数据；盘后延迟不影响“风险在积累还是释放”的判断。
- 如果以后要做执行层（精确买卖点），再考虑 Alpaca/Polygon 等实时数据；当前不需要。
- 券商 “公开数据” 能接，但不等于免费实时；交易所对实时行情收费，免费档通常是延迟数据或单交易所（IEX）。

## 五个市场，四套驱动

| 市场 | 代理 | 主要驱动 | 不能和谁混用 |
|---|---|---|---|
| 美股大盘 | SPY | 利率、信用、盈利、广度 | 不能代表中概 |
| 纳指/科技 | QQQ | 利率/久期、AI capex、半导体、集中度 | 不能代表大盘 |
| 半导体 | SOXQ | AI capex、存储周期、中国 DUV | 波动最大，仓位要减半 |
| 中概 ADR | KWEB / FXI | 中国政策、ADR 审计/退市、人民币、港股流动性 | 美股 VIX 只是次要输入 |

七姐妹（AAPL/MSFT/GOOGL/AMZN/NVDA/META/TSLA）逐只判断，不用一个“Mag7 状态”掩盖分化。

## 状态机

| 阶段 | 含义 | 规则动作 |
|---|---|---|
| 6 趋势健康 | 价格在 50/200 日线上方，且 50 日线在 200 日线上方，回撤 <5% | 持有，跌破 200 日线再减 |
| 5 趋势确认 | 价格在 50/200 日线上方，且 50 日线在 200 日线上方，回撤 ≥5% | 持有/可加，止损 200 日线 |
| 4a 上升趋势回调 | 价格在 200 日线上方、50 日线下方 | 观察/持有，不新加 |
| 4b 修复 | 价格在 200 日线下方，但重新站上 50 日线 | 小仓加（≤1/2），止损 50 日线/60 日低点较低者 |
| 3 止跌观察 | 跌破 20 日线至少 5 天后，连续 5 天站稳 20 日线 | 试 1/3，止损 60 日低点 |
| 2 深度下跌 | 距高点 ≥20%，或 VIX ≥35 | 不抄底；已有仓位不摊平；没有仓位不新开 |
| 1 下跌中 | 在 200 日线下方，但还没到 2/3 | 不新买，等 20 日线 |
| 0 数据不足/异常 | 历史不够、抓取失败、疑似拆股 | 观察，不操作 |

## 卡片里的“广度、信用、波动”

| 指标 | 看什么 | 恶化意味着 |
|---|---|---|
| 七姐妹广度 | 7 只里有几只在 200 日线上方 | 上涨只靠少数大票 |
| 等权/市值权 | RSP/SPY 的 20 日变化 | 等权跑输 = 广度差 |
| QQQ/半导体距 200 日线 | 价格离一年平均成本多远 | 趋势转弱 |
| VIX | 市场恐慌温度 | 上升 = 市场紧张 |
| 信用利差 | 企业债比国债贵多少 | 走阔 = 担心违约 |

每项都显示“20 天前 → 现在”，所以你能看到风险是在积累还是在释放，而不是只看到一个结论。

判断用收盘价、均线、VIX、信用利差、RSP/SPY 广度；不预测。动作是规则输出，不是投资建议。

## 白话原则

- 主文不出现 `top_adj`、分位、MA200 这类黑话；必须出现时，后面立刻解释。
- 每个市场都回答三件事：**现在什么状态 → 这意味着什么 → 现在怎么做**。
- 每条判断后面跟“什么会改变它”，避免把观点说成永久结论。
- 文末有“小白词典”，解释 200 日线、20 日线、VIX、信用利差、bp、等权/市值权、阶段 1-6。

## 本地运行

```bash
cd research/us_market_state
pip install -r ../../requirements.txt

python smoke_test.py               # 先确认数据源能拿到最近交易日

python run_daily.py --dry-run      # 每日短卡：只打印
python run_daily.py --shadow       # 每日短卡：推送带【干跑】前缀，不写状态
python run_daily.py                # 每日短卡：正式推送（当天只推一次）

python run_weekly.py --dry-run     # 周报全文：只打印
python run_weekly.py --shadow      # 周报全文：推送带【干跑】前缀
python run_weekly.py               # 周报全文：推送（同一周只推一次）

python -m pytest test_state.py -q  # 测试
python backtest.py                 # 分市场回测
```

飞书凭据：环境变量 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_CHAT_ID`（内部群）、
`FEISHU_WEBHOOK_URL`（外部群，可选）；或 `~/.market-radar/feishu.env`（与 A 股周期面板共用）。

## 回测参考（月线 10 月均线规则）

| 市场 | 买入持有 CAGR / 最大回撤 | 10 月线 CAGR / 最大回撤 | 切换次数 |
|---|---|---|---|
| SPY 2001–2026 | 7.8% / -52.2% | 6.6% / **-23.3%** | 40 |
| QQQ 2001–2026 | 12.9% / -47.7% | 10.6% / **-19.2%** | 30 |
| SOXQ 2022–2026 | 21.2% / -40.9% | 24.8% / **-25.0%** | 6 |
| KWEB 2018–2026 | -11.3% / -78.6% | **+1.9%** / -39.5% | 12 |

说明：只含价格，不含股息、税、交易成本；中概即使有规则，最大回撤仍有 -40%~-53%，
所以中概的主要保护是仓位上限，不是择时。
FXI 历史数据有 2008-07-24 单日 -68% 的异常跳变（疑似数据错误），回测跳过，不拿错误数据充数。

## 定时

| 工作流 | 时间 | 说明 |
|---|---|---|
| `daily-report.yml` | 北京周二~周五 07:30 | 每日短卡；当天已推则跳过 |
| `us-market-state.yml` | 周六 09:00 | 周报全文，覆盖周五美股 |

GitHub 的定时任务可能延迟几分钟到几小时；这是日频状态判断，不是实时交易系统。

## 边界

- 这是**状态判断**，不是顶底预测；它不知道明天涨跌。
- 状态会滞后：确认趋势修复时，第一段反弹已经错过了一部分。
- 数据源：akshare 美股日线 + FRED；抓取失败时用缓存，报告会标注数据质量。
- 疑似拆股/单日异常跌超 35% 的市场，本期跳过并提示，不会把拆股误判成“崩盘”。
- 数据日期落后超过 2 天会在卡片顶部警告；超过 4 天不推送。
- 中概的中国政策事件目前没有自动 NLP 判断；遇到单日 ±5% 的大波动，请自己查新闻。
